# Recovered footage · script as built

Every line spoken in the seven footage reels (`js/menu/footage.js`, functions `T1`–`T7`) and the voices the menu's secrets let through (`js/menu/secrets.js`). IDs `C1-001` and on are for voice files. In the game these lines are spoken by the device's own voices (`js/menu/call-sound.js`), each character cast with a pitch and speed; *tone* is how it is said (whisper, tired, sharp, human = ELYRA's voice breaking through as a person, echo = Rhen's voice coming back slowed).
