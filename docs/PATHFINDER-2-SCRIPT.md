# Pathfinder · Arc 02 · Dead Ground · script as built (Oct 22, first playable)

Built from Bryce's S2 brief (`docs/lore-2026-10-22/pathfinder-the-lost-expedition.md`). The opening exchange, the basin exchange and the Marsh/Rhen scene are the brief's lines; everything else is Claude's draft for Bryce to rewrite. The object stays unnamed ("the case").

**Flow:** the wreck at dawn (Landry's beacon) → salvage: ammunition, med kit, stabilize Okafor, the case, the locator → the dead ground (a burned convoy, black glass that still burns, pale stone fragments, red scouts) → the basin: two Herald sides killing each other; both fire on you if you come within ~36 m → the graveyard: Thorne pulls two orders from two terminals (optional) → the canyon (riflemen on the rims) → Dropship Two → hold ~60 s while Landry brings the core back; once, near the case, everyone close stops firing for a few seconds (unexplained) → the case pulses, its light points north; over the rim, the white city.

**Herald soldiers** are a placeholder: the Empty Host trooper model tinted (red side / amber side) with a light on the chest and back for the insignia, until there is a Herald model.

**Test jumps:** `pathfinder-2.html?at=desert`, `basin`, `grave`, `canyon`, `defend`.
